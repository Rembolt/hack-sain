
Run Database Server

    uvicorn main:app --reload --port 8001
        in terminal

Base URL

http://localhost:8001

Available Endpoints

GET /complaints?cursor=&limit=100
    Returns one chunk of complaints changed after the cursor.
    cursor is empty for the first chunk, then next_cursor from the last response.
    limit is 1 to 500 and defaults to 100.

    {
      "chunk": [ ...rows... ],
      "next_cursor": "2026-09-27T09:00:00Z|COMP-002",
      "has_more": false
    }

POST /complaints
    Creates a new complaint.

GET /accounts/{account_id}/complaints
    Returns all complaints associated with a customer account.

Swagger Documentation

http://localhost:8001/docs

Example

GET http://localhost:8001/complaints?limit=100

Response:
{
  "chunk": [
    {
      "complaint_id": "COMP-002",
      "ticket_number": "TKT-002",
      "account_id": "ACC-100002",
      "reason": "Power Outage"
    }
  ],
  "next_cursor": "2026-09-27T09:00:00Z|COMP-002",
  "has_more": false
}
